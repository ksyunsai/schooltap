# 스쿨탭 차량용 앱

학원 차량에서 키링을 읽는 안드로이드 시험판입니다. 안드로이드 7 이상이며 NFC를 지원하는 기기에서 사용합니다. 학교 등록 화면과 NFC 읽기는 기기에서 실행합니다. 승하차 판단, 중복 태그 처리, GPS 화면과 보호자 알림 요청은 배포 중인 스쿨탭 차량 웹 화면을 사용합니다.

## 갤럭시에서 첫 연결

1. 시험용 APK를 갤럭시에 설치하고 **스쿨탭 차량용**을 엽니다.
2. 기존 스쿨탭 관리자 화면에서 **기기별 전용 QR 배포 및 클라우드 연동 → 버스 단말기 전용 → 단말기 링크 복사**를 선택합니다. 클라우드에 연결한 학교의 링크를 사용합니다.
3. 설치한 앱에 링크를 붙여넣고 **차량 단말기 연결**을 누릅니다. 다음 실행부터 같은 학교를 엽니다.
4. 갤럭시 설정에서 NFC를 켜고 차량 화면에서 **실물 NFC 켜기**를 누릅니다. 현재 운행 방향을 확인한 다음 테스트 학생의 등록된 키링을 뒷면 안테나에 댑니다. 기존 관리자 화면에 같은 학생의 기록이 한 건 생기는지, 연결된 보호자 기기에 예상한 언어로 알림이 도착하는지 확인합니다.

차량 화면은 인터넷 연결이 필요합니다. 운행 중 앱이 앞에 있을 때 화면을 켜 두며, 전원 버튼으로 잠그거나 다른 앱으로 이동하면 NFC 읽기를 중단합니다. 위치 권한은 차량 위치를 사용할 때 요청합니다. 부모는 기존 보호자용 스쿨탭을 계속 사용합니다.

## 개발 및 검증

프로젝트의 `mobile/android` 폴더를 Android Studio에서 열 수 있습니다. Android SDK Platform 36, Build-Tools 36.0.0, JDK 17 이상이 필요합니다. 저장소 루트에서 실행합니다.

```sh
node --test mobile/android/tests/*.test.cjs
cd mobile/android
./gradlew :app:assembleDebug
```

Windows에서는 `gradlew.bat :app:assembleDebug`로 빌드합니다. Gradle 결과는 `app/build/outputs/apk/debug/app-debug.apk`입니다. 같은 폰에 덮어쓰는 시험판은 동일한 서명 키로 빌드해야 합니다. 저장소에는 서명 키와 학교 접속 정보를 보관하지 않습니다.
